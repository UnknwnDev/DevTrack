# DevTracks — Developer Growth Tracker
Track coding sessions, learning goals, completed projects, and weekly progress in a personal developer dashboard.

A personal dashboard for tracking coding time, learning goals, and project milestones.
- Log coding sessions with duration and topic.
- Create learning goals such as “Practice SQL for 5 hours this week.”
- Track personal projects and mark milestones as complete.
- Display weekly coding hours and topic breakdowns.
- Show daily activity, streaks, and goal progress.
